TU ESPACIO DE ATENCIÓN

De Claude al cliente.
Sin pasos de más.

La respuesta que Claude envía con la herramienta de la imprenta llega directamente a Telegram.

01

Telegram recibe

El cliente inicia una conversación privada con el bot. El programa guarda sus mensajes y los muestra aquí.

02

Claude prepara y envía

Desde Claude Desktop, el asistente lee la solicitud, consulta las fuentes y utiliza responder_cliente. Esa acción envía su respuesta al cliente y registra el resultado.

03

El panel se actualiza

Ves la conversación, el estado de entrega y las fuentes utilizadas. No hay un botón de aprobación ni necesitas copiar el texto a Telegram.

CON TU CUENTA ACTUAL

Atender desde Claude Desktop

Con las herramientas AIEC conectadas, puedes utilizar esta instrucción para atender un grupo de conversaciones:

Atiende hasta cinco solicitudes pendientes de Impresos San Martín. Consulta el catálogo y sus fuentes. Redacta respuestas breves y usa responder_cliente para enviarlas directamente a cada cliente. No pidas aprobación en el panel. Comprueba el resultado de los envíos.

Claude debe estar en una sesión activa para ejecutar sus herramientas. El envío directo no necesita la API de pago. Si acabas de actualizar el proyecto, reinicia Claude Desktop una vez para cargar la nueva herramienta.

Generación en segundo plano y límites

El programa puede enviar una respuesta de Claude sin aprobación. Para que también inicie la redacción cuando Claude Desktop no está en una sesión activa, hace falta su API con créditos. Esa opción permanece desactivada.

Este canal atiende mensajes de texto. No confirma pagos, producción ni fechas de entrega. Los importes investigados son referencias de otros proveedores. Si Telegram no confirma una entrega, el sistema conserva el intento y evita duplicarlo.
