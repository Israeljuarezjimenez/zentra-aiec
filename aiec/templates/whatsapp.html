Configurar el webhook en Meta

Un webhook es la dirección HTTPS a la que Meta envía los mensajes. El receptor de WhatsApp está separado del panel privado.

  1. Abre Configurar WhatsApp.command para guardar el secreto de la aplicación sin mostrarlo. Se obtiene en la configuración básica de tu aplicación de Meta; no es el token de acceso.
  2. El configurador habilita WhatsApp. Reinicia AIEC; el receptor usará el puerto local {{ connection.webhook_port }}.
  3. Conecta una dirección HTTPS pública a ese puerto. En Meta, la dirección de devolución debe terminar en /webhook/whatsapp. El puerto del panel privado no se publica.
  4. Verifica la dirección en Meta con el siguiente token y suscribe el campo messages.
{% if verify_token %}

Este token valida la dirección del webhook. El token de acceso a WhatsApp no se muestra en el panel.

{% else %}

Genera y guarda un token aleatorio en WHATSAPP_VERIFY_TOKEN antes de verificar la dirección.

{% endif %}

Alcance de esta conexión

Recibe texto, conserva el historial y responde al mismo cliente por WhatsApp. Solo envía mensajes de servicio dentro de las 24 horas posteriores al mensaje del cliente. No envía plantillas ni campañas.

La aceptación de un envío por Meta, su entrega y su lectura se registran como estados diferentes. Si un envío no puede confirmarse, se conserva el intento sin repetirlo automáticamente.
