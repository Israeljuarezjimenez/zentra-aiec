# Sitios web informativos y catálogos

Versión 1.0 · 15 de octubre de 2026. Material de demostración de Estudio Órbita. Alcances y precios de referencia propuestos para el proyecto; no son tarifas comerciales aprobadas de una agencia real.

## Comparación de planes web

Las referencias por proyecto son Web Esencial (WEB-E), $6,500 MXN; Web Negocio (WEB-N), $11,000 MXN; y Web Catálogo (WEB-C), $17,500 MXN. Son importes orientativos propuestos para los alcances de demostración, no tarifas aprobadas ni totales fiscales. Dominio, alojamiento, correo, mantenimiento y servicios externos se cotizan aparte. Ninguno incluye carrito o pagos en línea.

## Web Esencial: presentación en una página

Web Esencial propone una página con hasta cinco secciones y diseño para celular y computadora, por una referencia de $6,500 MXN por proyecto. Puede mostrar servicios o menú resumido, dirección, horario y botón de contacto. Incluye carga de materiales y dos rondas de ajustes. El plazo propuesto es de 7 a 10 días hábiles con materiales completos y alcance aprobado; no es una fecha reservada.

## Web Negocio: varias páginas y fichas informativas

Web Negocio propone hasta cinco páginas y doce fichas de productos o servicios por una referencia de $11,000 MXN por proyecto. Incluye contacto, ubicación, organización básica de títulos para buscadores, dos rondas de ajustes y una sesión remota de entrega de hasta 45 minutos. El plazo estimado es de 12 a 18 días hábiles después de reunir materiales y aprobar el alcance, sujeto a disponibilidad.

## Web Catálogo: mayor variedad de productos

Web Catálogo propone hasta ocho páginas y cuarenta fichas informativas por una referencia de $17,500 MXN por proyecto. Incluye organización por categorías, contactos, dos rondas de ajustes y una entrega remota de hasta 60 minutos. El plazo orientativo es de 20 a 25 días hábiles con insumos completos. Presentar productos y enlazar a contacto no equivale a una tienda con cobros, inventario o envíos automáticos.

## Dominio, alojamiento y cambios posteriores

El dominio es el nombre del sitio; el alojamiento es el servicio donde se publica. No se incluyen en estas tarifas de referencia y no se contratan automáticamente desde Zentra. Se plantea que el cliente conserve su titularidad. Cargar nuevas fichas, ampliar páginas, mantener el sitio después de la entrega o conectar sistemas externos requiere definir un alcance adicional.
