# WEB-E · Web Esencial

Versión 1.0 · 15 de octubre de 2026. Material de demostración de Estudio Órbita. Alcances y precios de referencia propuestos para el proyecto; no son tarifas comerciales aprobadas de una agencia real.

## Honorario y periodo de Web Esencial

El plan de demostración Web Esencial (WEB-E) tiene un honorario de referencia propuesto de $6,500 MXN por proyecto, pago único del alcance descrito. Es una cifra orientativa para elaborar propuestas del proyecto, no una tarifa comercial aprobada ni un total final con impuestos. El tratamiento fiscal y cualquier gasto externo se precisan en la cotización.

## Para quién y alcance de Web Esencial

Como propuesta de demostración, Web Esencial se orienta a: Negocio que necesita una página sencilla para presentar sus servicios y facilitar el contacto. Alcance base propuesto: Un sitio de una sola página con hasta cinco secciones: presentación, servicios o menú resumido, ubicación, horario y contacto.

## Qué incluye Web Esencial

Dentro del alcance propuesto del plan de demostración Web Esencial:
- Diseño adaptable a celular y computadora para una página con hasta cinco secciones.
- Carga de textos e imágenes entregados por el cliente.
- Botón de contacto y mapa o enlace de ubicación si existen los datos.
- Dos rondas consolidadas de ajustes y una entrega de acceso al sitio acordado.

## Qué se cotiza aparte en Web Esencial

El honorario de referencia de Web Esencial no incluye:
- Dominio, alojamiento, correo, licencias y suscripciones de terceros.
- Carrito de compras, cobros en línea, reservaciones automáticas o aplicaciones móviles.
- Redacción extensa, fotografía, mantenimiento mensual y campañas de publicidad.

## Preparación y ajustes de Web Esencial

Web Esencial tiene este plazo estimado propuesto: Estimación de 7 a 10 días hábiles desde la recepción de materiales y aprobación del alcance; no es una fecha de entrega confirmada. El alcance de demostración contempla 2 rondas consolidadas de ajustes; las rondas se aplican al lote o diseño acordado, no a solicitudes ilimitadas.

## Uso en una propuesta al cliente

Se puede recomendar Web Esencial como opción inicial si coincide con la necesidad y el presupuesto del cliente. Al mencionar los $6,500 MXN, describirlos como honorario orientativo de la propuesta. No presentar esta ficha de demostración como un contrato aceptado, una tarifa real de otra agencia o una fecha reservada. Los datos que falten se anotan para revisión interna, sin interrogar al cliente.
