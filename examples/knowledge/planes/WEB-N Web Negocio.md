# WEB-N · Web Negocio

Versión 1.0 · 15 de octubre de 2026. Material de demostración de Estudio Órbita. Alcances y precios de referencia propuestos para el proyecto; no son tarifas comerciales aprobadas de una agencia real.

## Honorario y periodo de Web Negocio

El plan de demostración Web Negocio (WEB-N) tiene un honorario de referencia propuesto de $11,000 MXN por proyecto, pago único del alcance descrito. Es una cifra orientativa para elaborar propuestas del proyecto, no una tarifa comercial aprobada ni un total final con impuestos. El tratamiento fiscal y cualquier gasto externo se precisan en la cotización.

## Para quién y alcance de Web Negocio

Como propuesta de demostración, Web Negocio se orienta a: Negocio que necesita varias páginas para explicar servicios, mostrar información y recibir contactos. Alcance base propuesto: Hasta cinco páginas y un catálogo informativo de hasta doce productos o servicios, sin pagos en línea.

## Qué incluye Web Negocio

Dentro del alcance propuesto del plan de demostración Web Negocio:
- Diseño adaptable para hasta cinco páginas.
- Carga de hasta doce fichas informativas con materiales entregados por el cliente.
- Botón de contacto, ubicación y organización básica de títulos para buscadores.
- Dos rondas consolidadas de ajustes y una sesión remota de entrega de hasta 45 minutos.

## Qué se cotiza aparte en Web Negocio

El honorario de referencia de Web Negocio no incluye:
- Dominio, alojamiento, correo y herramientas externas de pago.
- Tienda con cobros, inventario sincronizado, logística y sistema de reservas.
- Posicionamiento garantizado en buscadores, producción audiovisual y mantenimiento mensual.

## Preparación y ajustes de Web Negocio

Web Negocio tiene este plazo estimado propuesto: Estimación de 12 a 18 días hábiles con contenidos completos y alcance aprobado; el calendario final se confirma por escrito. El alcance de demostración contempla 2 rondas consolidadas de ajustes; las rondas se aplican al lote o diseño acordado, no a solicitudes ilimitadas.

## Uso en una propuesta al cliente

Se puede recomendar Web Negocio como opción inicial si coincide con la necesidad y el presupuesto del cliente. Al mencionar los $11,000 MXN, describirlos como honorario orientativo de la propuesta. No presentar esta ficha de demostración como un contrato aceptado, una tarifa real de otra agencia o una fecha reservada. Los datos que falten se anotan para revisión interna, sin interrogar al cliente.
