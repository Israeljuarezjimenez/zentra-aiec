# WEB-C · Web Catálogo

Versión 1.0 · 15 de octubre de 2026. Material de demostración de Estudio Órbita. Alcances y precios de referencia propuestos para el proyecto; no son tarifas comerciales aprobadas de una agencia real.

## Honorario y periodo de Web Catálogo

El plan de demostración Web Catálogo (WEB-C) tiene un honorario de referencia propuesto de $17,500 MXN por proyecto, pago único del alcance descrito. Es una cifra orientativa para elaborar propuestas del proyecto, no una tarifa comercial aprobada ni un total final con impuestos. El tratamiento fiscal y cualquier gasto externo se precisan en la cotización.

## Para quién y alcance de Web Catálogo

Como propuesta de demostración, Web Catálogo se orienta a: Negocio que requiere presentar una variedad mayor de productos y dirigir consultas a un canal de contacto. Alcance base propuesto: Hasta ocho páginas y cuarenta fichas de productos o servicios; catálogo informativo con contacto, sin carrito ni pagos en línea.

## Qué incluye Web Catálogo

Dentro del alcance propuesto del plan de demostración Web Catálogo:
- Diseño adaptable para hasta ocho páginas.
- Carga de hasta cuarenta fichas con textos e imágenes del cliente.
- Organización de las fichas por categorías y botones de contacto.
- Dos rondas consolidadas de ajustes y una sesión remota de entrega de hasta 60 minutos.

## Qué se cotiza aparte en Web Catálogo

El honorario de referencia de Web Catálogo no incluye:
- Cobro en línea, inventario en tiempo real, envíos y aplicaciones móviles.
- Dominio, alojamiento, correo, licencias y recursos de pago.
- Mantenimiento mensual, captura de nuevas fichas tras la entrega y posicionamiento garantizado.

## Preparación y ajustes de Web Catálogo

Web Catálogo tiene este plazo estimado propuesto: Estimación de 20 a 25 días hábiles después de reunir materiales y aprobar el alcance; no se promete una fecha antes de revisar capacidad. El alcance de demostración contempla 2 rondas consolidadas de ajustes; las rondas se aplican al lote o diseño acordado, no a solicitudes ilimitadas.

## Uso en una propuesta al cliente

Se puede recomendar Web Catálogo como opción inicial si coincide con la necesidad y el presupuesto del cliente. Al mencionar los $17,500 MXN, describirlos como honorario orientativo de la propuesta. No presentar esta ficha de demostración como un contrato aceptado, una tarifa real de otra agencia o una fecha reservada. Los datos que falten se anotan para revisión interna, sin interrogar al cliente.
